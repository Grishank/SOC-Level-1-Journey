# 🧠 Room Overview

**Linux Logging For SOC** introduces the most important Linux log sources and demonstrates how SOC analysts use them to investigate authentication attempts, monitor system activity, and detect suspicious behavior. The room also covers text log analysis, runtime monitoring, and Linux auditing with **Auditd**.

---

# 🎯 Learning Objectives

- Understand Linux logging fundamentals
- Analyze authentication logs
- Investigate common Linux log files
- Monitor runtime activity
- Use Auditd for auditing
- Improve Linux threat detection skills
