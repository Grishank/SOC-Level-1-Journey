# 🧠 Room Overview

**Linux Threat Detection 1** introduces common **Initial Access** techniques used by attackers against Linux systems and teaches SOC analysts how to detect them through Linux logs, SSH authentication events, and service monitoring. The room focuses on identifying unauthorized SSH access, compromised services, and other common Linux intrusion methods.

---

# 🎯 Learning Objectives

- Understand Linux Initial Access techniques
- Detect SSH attacks
- Monitor authentication logs
- Identify compromised network services
- Analyze Linux security events
- Improve Linux threat detection skills
