# 🧠 Room Overview

**Linux Threat Detection 3** focuses on the final stages of a Linux compromise. The room teaches SOC analysts how attackers establish **reverse shells**, perform **privilege escalation**, maintain **persistence**, and continue operating on compromised Linux systems. It emphasizes recognizing attacker behavior through system logs, authentication records, process monitoring, and persistence mechanisms.

---

# 🎯 Learning Objectives

- Understand reverse shell techniques
- Detect privilege escalation attempts
- Identify Linux persistence mechanisms
- Monitor malicious account creation
- Investigate attacker activity through logs
- Improve Linux incident detection skills
