# 🧠 Overview

The **THM SOC Simulator** is a realistic blue-team simulation where I acted as a SOC Analyst responsible for monitoring and triaging security alerts generated within a simulated enterprise environment.

During this scenario, I investigated alerts, distinguished true positives from false positives, prioritized incidents based on severity, and successfully prevented a simulated security breach before it could impact the organization.

Unlike traditional CTF-style rooms, this simulator focuses on real SOC workflows and decision-making under pressure.

# 🔍 Investigation Workflow

During the simulation I:

- Reviewed incoming security alerts
- Distinguished legitimate threats from normal activity
- Investigated suspicious processes and executions
- Correlated multiple events before making decisions
- Escalated confirmed malicious alerts
- Closed benign alerts after verification
- Managed incidents while minimizing false positives

This closely resembles the day-to-day workflow of a Tier 1 SOC Analyst.

---

# 🧩 Key Lessons Learned

- Accurate triage is more important than speed alone.
- Proper evidence gathering reduces false positives.
- Correlating multiple alerts provides better context than investigating isolated events.
- Incident prioritization is critical when handling multiple simultaneous alerts.
- Effective SOC operations require balancing investigation depth with response time.
