# 🧠 Room Overview

This room introduces the role of a **Junior Security Analyst** and explains how Security Operations Centers (SOCs) work in real-world environments.

The room focuses on:
- SOC fundamentals
- Alert monitoring
- Incident investigation
- Security monitoring workflows
- Blue team responsibilities

---

# 🎯 Learning Objectives

- Understand the role of a Security Analyst
- Learn what a SOC does
- Understand alert investigation workflows
- Learn basic incident response concepts
- Understand blue team operations

---

# 👨‍💻 Task 1 — Junior Security Analyst Journey

A Junior Security Analyst is responsible for:
- Monitoring alerts
- Investigating suspicious activity
- Reviewing logs
- Escalating incidents
- Documenting findings

---

# 🏢 Task 2 — Security Operations Center (SOC)

A SOC is responsible for:
- Detecting threats
- Monitoring systems
- Investigating incidents
- Protecting organizational assets

## Common SOC Activities

- SIEM monitoring
- Log analysis
- Alert triage
- Threat investigation
- Incident response

---

# 📅 Task 3 — A Day in the Life of a Security Analyst

Typical analyst workflow:

```text
Monitor Alerts → Investigate Logs → Analyze Activity → Escalate Incident → Document Findings
```

## Common Tools Used

| Tool | Purpose |
|---|---|
| SIEM | Security monitoring |
| EDR | Endpoint protection |
| IDS/IPS | Threat detection |
| Firewalls | Network security |
