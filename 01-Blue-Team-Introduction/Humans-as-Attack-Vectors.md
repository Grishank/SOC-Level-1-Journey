# 🧠 Room Overview

This room explains how humans are commonly targeted in cyber attacks through social engineering, phishing, manipulation, and psychological tactics.

The room focuses on:
- Human attack vectors
- Social engineering
- Phishing attacks
- Human behavior exploitation
- Defensive awareness practices

---

# 🎯 Learning Objectives

- Understand why humans are targeted
- Learn common social engineering attacks
- Understand phishing techniques
- Learn defensive security awareness concepts
- Understand the SOC role in defending users

---

# 👥 Task 1 — Introduction

Learned how attackers often target people instead of systems because humans are usually the weakest security layer.

---

# 🧠 Task 2 — The Human Element

Important human weaknesses attackers exploit:
- Trust
- Curiosity
- Fear
- Urgency
- Lack of awareness

Common social engineering methods:
- Phishing emails
- Fake login pages
- Phone scams
- Malicious attachments
- Impersonation attacks

---

# 🎣 Task 3 — Attacks on Humans

Common attack types covered:

| Attack Type | Purpose |
|---|---|
| Phishing | Steal credentials |
| Spear Phishing | Target specific users |
| Smishing | SMS phishing |
| Vishing | Voice phishing |
| Baiting | Trick users into unsafe actions |

---

# 🛡️ Task 4 — Defending Humans

Ways organizations defend users:
- Security awareness training
- Multi-factor authentication (MFA)
- Email filtering
- Reporting suspicious activity
- Password security practices

SOC teams help by:
- Monitoring phishing campaigns
- Investigating suspicious emails
- Alerting employees
- Responding to compromised accounts

> “Attackers often target people first because manipulating human behavior is easier than breaking strong security systems.”
