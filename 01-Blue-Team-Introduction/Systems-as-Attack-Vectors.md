# 🧠 Room Overview

This room explains how attackers exploit vulnerable and misconfigured systems to gain unauthorized access, execute malicious actions, and compromise organizations.

The room focuses on:
- System vulnerabilities
- Misconfigurations
- Common attack methods
- Weak security practices
- Defensive protection concepts

---

# 🎯 Learning Objectives

- Understand what systems are in cybersecurity
- Learn how attackers target systems
- Understand vulnerabilities and exploits
- Learn about misconfigurations
- Understand defensive security practices

---

# 🖥️ Task 1 — Introduction

Learned how attackers target systems that contain weak security controls, outdated software, or poor configurations.

---

# ⚙️ Task 2 — Definition of System

A system can include:
- Computers
- Servers
- Applications
- Databases
- Cloud services
- Network devices

Attackers search for weaknesses in these systems to gain access.

---

# 💣 Task 3 — Attacks on Systems

Common attacks covered:

| Attack Type | Purpose |
|---|---|
| Malware | Damage or control systems |
| Ransomware | Encrypt files for payment |
| Brute Force | Guess passwords |
| Exploitation | Abuse software flaws |
| Privilege Escalation | Gain higher access |

---

# 🔓 Task 4 — Vulnerabilities

A vulnerability is a weakness that attackers can exploit.

Common causes:
- Outdated software
- Weak passwords
- Missing patches
- Insecure applications
- Poor access controls

---

# ⚠️ Task 5 — Misconfigurations

Examples of dangerous misconfigurations:
- Open ports
- Default credentials
- Disabled security settings
- Excessive permissions
- Publicly exposed services

Misconfigurations are one of the most common causes of security breaches.
