# 🧠 Room Overview

**Detecting Web DDoS** introduces Denial-of-Service (DoS) and Distributed Denial-of-Service (DDoS) attacks, their motivations, detection methods, and defensive strategies. The room teaches SOC analysts how to recognize abnormal traffic patterns using log analysis, SIEM platforms, and monitoring tools to identify and respond to availability attacks.

---

# 🎯 Learning Objectives

- Understand DoS and DDoS attacks
- Learn attacker motivations
- Analyze web server logs for DDoS indicators
- Detect attacks using SIEM platforms
- Understand DDoS mitigation techniques
- Build practical DDoS detection skills

---

# 📌 Task 1 — Introduction

Introduced the fundamentals of DoS and DDoS attacks and explained why availability attacks are a major threat to online services.

---

# 📌 Task 2 — DoS and DDoS Attacks

Learned how denial-of-service attacks disrupt services by overwhelming servers with excessive traffic.

Covered:

- DoS attacks
- DDoS attacks
- Botnets
- Resource exhaustion
- Traffic flooding

---

# 📌 Task 3 — Attack Motives

Explored the common reasons attackers launch DDoS attacks.

Focused on:

- Financial extortion
- Service disruption
- Hacktivism
- Competitive attacks
- Diversion tactics

---

# 📌 Task 4 — Log Analysis

Learned how web server logs reveal signs of denial-of-service attacks.

Analyzed:

- Request spikes
- Repeated IP activity
- HTTP status codes
- Traffic anomalies
- Access log patterns

---

# 📌 Task 5 — Leveraging SIEMs

Explored how SIEM platforms detect large-scale web attacks through centralized monitoring and alerting.

Studied:

- Event correlation
- Alert generation
- Traffic monitoring
- Dashboards
- Threat detection

---

# 📌 Task 6 — Defense

Learned defensive measures used to protect web applications from DoS and DDoS attacks.

Covered:

- Web Application Firewalls (WAF)
- Rate limiting
- Traffic filtering
- Load balancing
- DDoS mitigation services

---

- Distributed Denial of Service (DDoS)

- Web Application Firewall (WAF)
- SIEM
- Availability Attacks
- Network Monitoring

---

# 💬 Key Takeaway

> "Detecting DDoS attacks requires continuous monitoring of traffic patterns, log analysis, and SIEM correlation to quickly identify abnormal spikes in activity and respond before services become unavailable."
