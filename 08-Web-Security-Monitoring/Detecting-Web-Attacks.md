# 🧠 Room Overview

**Detecting Web Attacks** teaches how SOC analysts identify malicious web activity by analyzing web server logs, HTTP requests, network traffic, and defensive technologies. The room introduces both client-side and server-side attacks while demonstrating how to detect them using logs, network monitoring, and Web Application Firewalls (WAFs).

---

# 🎯 Learning Objectives

- Understand common web attacks
- Identify client-side and server-side threats
- Analyze web server logs
- Detect attacks through network traffic
- Learn how Web Application Firewalls work
- Build practical web attack detection skills
