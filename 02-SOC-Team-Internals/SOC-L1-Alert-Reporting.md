# 📌 Task 1 — Introduction

Learned how proper reporting and communication are critical inside a SOC environment to ensure incidents are handled quickly and accurately.

---

# 🚨 Task 2 — Alert Funnel

SOC alerts move through multiple stages:

```text
Event → Alert → Investigation → Escalation → Response → Closure
```

The alert funnel helps analysts filter noise and focus on real threats.

---

# 📝 Task 3 — Reporting Guide

Important elements in a SOC report:
- Alert summary
- Affected systems
- Severity level
- Investigation findings
- Indicators of compromise (IOCs)
- Recommended actions

Good reporting should be:
- Clear
- Accurate
- Concise
- Professional

---

# ⬆️ Task 4 — Escalation Guide

SOC analysts escalate alerts when:
- Threat severity is high
- Critical systems are impacted
- Malware or compromise is confirmed
- Additional expertise is required

## Common Escalation Levels

| Level | Responsibility |
|---|---|
| L1 Analyst | Initial investigation |
| L2 Analyst | Advanced analysis |
| L3 Analyst | Deep threat investigation |
| Incident Response Team | Containment & recovery |

---

# 💬 Task 5 — SOC Communication

Effective SOC communication includes:
- Timely updates
- Clear documentation
- Team collaboration
- Proper handoff between analysts
- Incident tracking

Poor communication can delay incident response and increase organizational risk.
