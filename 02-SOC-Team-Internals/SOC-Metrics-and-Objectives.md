# 📈 Task 2 — Core Metrics

Important SOC metrics include:

| Metric | Purpose |
|---|---|
| MTTD | Mean Time To Detect threats |
| MTTR | Mean Time To Respond |
| Alert Volume | Total alerts received |
| Escalation Rate | Alerts escalated to higher tiers |
| False Positive Rate | Incorrect alerts generated |

These metrics help SOC managers evaluate team performance and security posture.

---

# 🚨 Task 3 — Triage Metrics

SOC triage metrics focus on:
- Alert handling speed
- Investigation accuracy
- Case resolution time
- Escalation efficiency
- Analyst workload

Good triage processes reduce:
- Investigation delays
- Alert fatigue
- False positives

Ways SOC teams improve performance:
- Better alert tuning
- Analyst training
- Improved automation
- Stronger documentation
- Optimized workflows

Continuous improvement is important for handling growing security threats efficiently.
