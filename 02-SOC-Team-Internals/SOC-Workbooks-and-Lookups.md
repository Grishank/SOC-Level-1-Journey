# 🧠 Room Overview

This room explains how SOC analysts use internal documentation, asset inventories, network diagrams, and investigation workbooks to improve alert triage and incident investigations.

The room focuses on:
- Asset identification
- Identity tracking
- Network visibility
- SOC workbooks
- Investigation lookup resources

# 📌 Task 1 — Introduction

Learned how SOC analysts rely on internal documentation and lookup systems to investigate alerts more efficiently and reduce response time.

---

# 🖥️ Task 2 — Assets & Identities

SOC teams track:
- Devices
- Users
- Servers
- IP addresses
- Hostnames
- Departments

Important lookup information:
- Asset owner
- Device role
- User identity
- System criticality
- Network location

This helps analysts quickly determine whether activity is suspicious or expected.

---

# 🌐 Task 3 — Network Diagrams

Network diagrams help analysts understand:
- Network structure
- Device communication
- Critical systems
- Data flow
- Segmentation zones

These diagrams are useful during:
- Incident investigations
- Threat hunting
- Lateral movement analysis
- Malware investigations

---

# 📖 Task 4 — Workbooks Theory

SOC workbooks are step-by-step investigation guides used for:
- Alert triage
- Incident handling
- Threat validation
- Investigation consistency

Benefits of workbooks:
- Faster investigations
- Standardized procedures
- Reduced analyst mistakes
- Easier escalation

---

# 🛠️ Task 5 — Workbooks Practice

Typical workbook workflow:

```text
Receive Alert → Identify Asset → Check User Activity → Validate Threat → Escalate or Close
```

Analysts use:
- Asset databases
- Identity systems
- Internal documentation
- SIEM logs
- Investigation notes
