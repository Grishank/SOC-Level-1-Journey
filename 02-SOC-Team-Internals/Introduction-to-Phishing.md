# 🧠 Overview

This challenge simulated real SOC alert handling and incident reporting scenarios.

The objective was to:
- Review alerts
- Identify true positives and false positives
- Prioritize incidents
- Report findings correctly
- Improve triage accuracy

---

# 🔍 What I Practiced

- Alert triage
- Incident classification
- Reporting suspicious activity
- SOC investigation workflow
- Decision making under pressure

---

# ⚠️ Key Learning

I learned how important accurate alert classification is inside a SOC environment.

Incorrect handling of:
- phishing alerts
- suspicious activity
- malware indicators

can increase:
- MTTR (Mean Time To Respond)
- dwell time
- operational risk

# 💬 Key Takeaway

> “Efficient alert triage and proper reporting are critical skills for SOC analysts.”
