# ⚔️ Task 2 — MITRE ATT&CK Framework

The MITRE ATT&CK Framework is a knowledge base of real-world adversary behavior.

It organizes attacks into:

- Tactics
- Techniques
- Sub-techniques
- Procedures (TTPs)

ATT&CK helps defenders understand how attackers operate and improve detection capabilities.

---

# 🔍 Task 3 — ATT&CK in Operation

Organizations use ATT&CK to:

- Detect attacker behavior
- Improve SOC monitoring
- Build detection rules
- Perform threat hunting
- Conduct adversary emulation
- Evaluate security coverage

---

# 🧠 Task 4 — ATT&CK for Threat Intelligence

Threat intelligence teams map attacker activities to ATT&CK techniques to:

- Track threat actors
- Understand attack patterns
- Improve incident investigations
- Share standardized intelligence

This common language improves collaboration across security teams.

---

# 📊 Task 5 — Cyber Analytics Repository (CAR)

The Cyber Analytics Repository (CAR) contains:

- Detection analytics
- Hunting queries
- Security analytics
- Detection guidance
- ATT&CK mappings

CAR helps defenders implement practical detections for known attack techniques.

---

# 🛡️ Task 6 — MITRE D3FEND Framework

MITRE D3FEND complements ATT&CK by focusing on defensive techniques.

It provides guidance for:

- Detection
- Prevention
- Isolation
- Hardening
- Monitoring
- Incident response

D3FEND helps organizations map defensive controls against attacker techniques.
