# 🧠 Room Overview

This room introduces the **Cyber Kill Chain**, a framework developed by Lockheed Martin that describes the stages of a cyber attack from initial reconnaissance to achieving the attacker's objectives.

The room focuses on:
- Cyber Kill Chain phases
- Attack lifecycle
- Adversary behavior
- Detection opportunities
- Defensive strategies

---

# 🎯 Learning Objectives

- Understand the Cyber Kill Chain framework
- Learn each phase of a cyber attack
- Identify opportunities to stop attacks
- Understand attacker methodology
- Improve defensive monitoring

---

# 📌 Task 1 — Introduction

Learned how the Cyber Kill Chain breaks down cyber attacks into distinct stages, allowing defenders to detect and disrupt attacks before they succeed.

---

# 🔍 Task 2 — Reconnaissance

Attackers gather information about their target before launching an attack.

Examples:
- OSINT
- Employee information
- DNS enumeration
- Network scanning

---

# ⚔️ Task 3 — Weaponization

Attackers prepare malicious payloads by combining exploits with malware before delivering them to the victim.

---

# 📧 Task 4 — Delivery

The attacker delivers the malicious payload.

Common delivery methods:
- Phishing emails
- Malicious websites
- USB devices
- Drive-by downloads

---

# 💥 Task 5 — Exploitation

A vulnerability is exploited to execute malicious code on the victim's system.

Examples:
- Software vulnerabilities
- Macro-enabled documents
- Browser exploits

---

# 💻 Task 6 — Installation

The attacker installs malware or establishes persistence to maintain access to the compromised system.

Examples:
- Backdoors
- Remote Access Trojans (RATs)
- Persistence mechanisms

---

# 🌐 Task 7 — Command & Control (C2)

The compromised system communicates with the attacker's infrastructure to receive commands and transmit information.

Common techniques:
- HTTP/HTTPS
- DNS tunneling
- Encrypted communication

---

# 🎯 Task 8 — Actions on Objectives (Exfiltration)

The attacker performs their intended objectives, such as:

- Data theft
- Credential harvesting
- Ransomware deployment
- System destruction
- Lateral movement

---

# 🧪 Task 9 — Practice Analysis

Applied the Cyber Kill Chain by identifying each stage of an attack scenario and understanding where defenders can detect and interrupt malicious activity.

---

# 🔍 Key Concepts Learned

- Cyber Kill Chain

- Command & Control
- Defensive detection opportunities

---

# 💬 Key Takeaway

> “Breaking the attack chain at any stage can prevent attackers from reaching their final objective and significantly reduce the impact of a cyber attack.”
