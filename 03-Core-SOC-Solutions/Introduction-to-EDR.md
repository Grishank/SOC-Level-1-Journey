# 🧠 Room Overview

This room introduces **Endpoint Detection and Response (EDR)** and explains how modern endpoint security solutions detect, investigate, and respond to malicious activity beyond traditional antivirus software.

The room focuses on:
- EDR fundamentals
- Endpoint visibility
- Detection and response
- Endpoint telemetry
- Modern endpoint protection

---

# 🎯 Learning Objectives

- Understand what an EDR is
- Learn how EDR differs from antivirus
- Understand how EDR works
- Learn endpoint telemetry concepts
- Explore EDR detection and response capabilities

---

# 📌 Task 1 — Introduction

Learned why organizations use Endpoint Detection and Response solutions to continuously monitor endpoints and improve threat detection.

---

# 🖥️ Task 2 — What is an EDR?

An EDR solution provides:
- Continuous endpoint monitoring
- Threat detection
- Incident investigation
- Response capabilities

Unlike traditional antivirus, EDR provides visibility into endpoint behavior.

---

# 🛡️ Task 3 — Beyond the Antivirus

Traditional antivirus:
- Signature-based detection
- Limited visibility

EDR provides:
- Behavioral analysis
- Threat hunting
- Process monitoring
- Real-time investigation

---

# ⚙️ Task 4 — How an EDR Works

Basic EDR workflow:

```text
Endpoint Activity → Telemetry Collection → Threat Detection → Investigation → Response
```

EDR continuously analyzes endpoint activity to detect suspicious behavior.

---

# 📊 Task 5 — EDR Telemetry

Common telemetry collected includes:
- Process execution
- File activity
- Network connections
- User logins
- Registry changes

This data helps analysts investigate security incidents.

---

# 🚨 Task 6 — Detection and Response Capabilities

Common EDR capabilities:

| Capability | Purpose |
|---|---|
| Threat Detection | Identify malicious activity |
| Endpoint Visibility | Monitor endpoint behavior |
| Investigation | Analyze suspicious events |
| Isolation | Contain compromised devices |
| Automated Response | Stop ongoing attacks |
