This room introduces **Security Orchestration, Automation, and Response (SOAR)** and explains how it helps Security Operations Centers automate repetitive tasks, improve incident response, and streamline security workflows.

The room focuses on:

# 🏢 Task 2 — Traditional SOC and Challenges

Common challenges faced by SOC teams include:

- High alert volume
- Alert fatigue
- Manual investigations
- Slow incident response
- Repetitive tasks

These challenges reduce analyst productivity and increase response time.

---

# 🤖 Task 3 — Overcoming SOC Challenges with SOAR

SOAR helps by:

- Automating repetitive tasks
- Integrating multiple security tools
- Speeding up investigations
- Reducing analyst workload
- Improving response consistency

---

# 📖 Task 4 — Building SOAR Playbooks

A **Playbook** is a predefined workflow that automates incident response.

Typical playbook flow:

```text
Alert → Investigation → Enrichment → Decision → Automated Response → Case Closure
```

Playbooks ensure incidents are handled consistently and efficiently.
