# 🧠 Room Overview

This room introduces the **Elastic Stack (ELK)**, a powerful SIEM platform used by SOC analysts to collect, search, visualize, and investigate security logs.

The room focuses on:
- ELK Stack fundamentals
- Kibana interface
- KQL (Kibana Query Language)
- Data visualization
- Security dashboards

---

# 🎯 Learning Objectives

- Understand the Elastic Stack architecture
- Learn how Kibana is used for investigations
- Understand KQL basics
- Create visualizations
- Build dashboards for monitoring

# 🏗️ Task 2 — Elastic Stack Overview

The Elastic Stack consists of:

- Elasticsearch
- Logstash
- Kibana
- Beats

Together they collect, store, search, and visualize large amounts of log data.

---

# 🖥️ Task 3 — Lab Connection

Connected to the Elastic Stack lab environment and explored the Kibana interface used for security investigations.

---

# 🔍 Task 4 — Discover Tab

The **Discover** page allows analysts to:

- Search logs
- Filter events
- Investigate suspicious activity
- View indexed data

It is one of the most commonly used sections in Kibana.

---

# 🔎 Task 5 — KQL Overview

Kibana Query Language (KQL) helps analysts search logs efficiently.

Example searches include:
- Username
- IP Address
- Event ID
- Process Name
- Hostname

KQL makes threat hunting and investigations much faster.

---

# 📈 Task 6 — Creating Visualizations

Learned how Kibana can display log data using:

- Bar Charts
- Pie Charts
- Line Graphs
- Tables
- Metrics

Visualizations help identify trends and suspicious activity.

---

# 📊 Task 7 — Creating Dashboards

Dashboards combine multiple visualizations into one place for continuous monitoring.

They help SOC analysts:
- Track security events
- Monitor alerts
- Identify trends
- Improve incident response
