# 🧠 Room Overview

This room introduces **Splunk**, one of the most widely used Security Information and Event Management (SIEM) platforms. It covers the basic architecture, navigation, data ingestion, and how SOC analysts use Splunk to investigate security events.

The room focuses on:
- Splunk fundamentals
- SIEM architecture
- Navigating the Splunk interface
- Data ingestion
- Log investigation basics

---

# 🎯 Learning Objectives

- Understand what Splunk is
- Learn the main Splunk components
- Navigate the Splunk interface
- Learn how data is added into Splunk
- Understand how analysts search logs

---

# 📌 Task 1 — Introduction

Learned how Splunk helps SOC analysts collect, search, and investigate security logs from multiple systems.

---

# 🔗 Task 2 — Connect with the Lab

Connected to the Splunk lab environment and explored the web interface used for security investigations.

---

# 🏗️ Task 3 — Splunk Components

Core Splunk components include:

- Forwarders
- Indexers
- Search Heads
- Deployment Server

These components work together to collect, index, and search log data.

---

# 🧭 Task 4 — Navigating Splunk

Learned how to navigate:

- Search & Reporting
- Apps
- Dashboards
- Data Summary
- Search Bar

The search interface is the primary workspace for SOC analysts.

---

# 📂 Task 5 — Adding Data

Splunk can ingest data from:

- Windows Event Logs
- Linux Logs
- Firewall Logs
- Web Server Logs
- Security Appliances

Collected data is indexed for fast searching and analysis.
