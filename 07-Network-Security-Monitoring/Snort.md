# 🧠 Room Overview

**Snort** introduces one of the most widely used open-source Intrusion Detection and Intrusion Prevention Systems (IDS/IPS). The room covers Snort's different operating modes, packet analysis capabilities, rule creation, and traffic investigation using PCAP files.

It provides hands-on experience using Snort to detect malicious activity, inspect network traffic, and build custom detection rules commonly used by SOC analysts.

---

# 🎯 Learning Objectives

- Understand IDS and IPS concepts
- Learn Snort architecture
- Use Snort in multiple operating modes
- Analyze network packets
- Investigate PCAP files
- Write and understand Snort rules
- Detect malicious network activity
