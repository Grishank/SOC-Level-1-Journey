# 🧠 Room Overview

**Network Discovery Detection** focuses on how attackers perform reconnaissance to identify hosts, services, and network assets before launching attacks. The room explains common discovery techniques, different types of network scanning, and how defenders can detect reconnaissance activity through network monitoring and security logs.

It provides practical knowledge that helps SOC analysts recognize early signs of intrusion during the reconnaissance phase of the Cyber Kill Chain.

---

# 🎯 Learning Objectives

- Understand network discovery techniques
- Learn how attackers perform reconnaissance
- Differentiate internal and external scanning
- Compare horizontal and vertical scans
- Understand scanning mechanics
- Detect reconnaissance activity
- Improve network monitoring skills
