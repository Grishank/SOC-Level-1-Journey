# 🧠 Room Overview

**Invite Only** is a practical Cyber Threat Intelligence investigation where you analyze multiple suspicious artifacts to determine whether an organization has been compromised. Instead of learning individual concepts, this room simulates a real SOC investigation by requiring analysts to correlate indicators, enrich threat intelligence, and build an accurate picture of attacker activity.

---

# 🎯 Learning Objectives

- Perform a complete threat intelligence investigation
- Analyze suspicious Indicators of Compromise (IOCs)
- Correlate multiple artifacts
- Enrich IPs, domains, hashes, and URLs
- Identify attacker infrastructure
- Produce actionable threat intelligence findings

---

# 📌 Task 1 — Invite Only Investigation

Completed a practical investigation involving multiple suspicious artifacts.

Performed the following activities:

- Investigated suspicious IP addresses
- Enriched malicious domains
- Analyzed file hashes
- Verified URL reputation
- Correlated Indicators of Compromise (IOCs)
- Reviewed threat intelligence reports
- Distinguished benign from malicious infrastructure
- Built an overall threat assessment

The investigation required combining information from several intelligence sources to determine the attacker's infrastructure and identify malicious activity.
