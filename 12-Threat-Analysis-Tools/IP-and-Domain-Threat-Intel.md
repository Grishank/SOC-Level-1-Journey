# 🧠 Room Overview

**IP and Domain Threat Intel** introduces SOC analysts to the process of enriching IP addresses and domain names using Open Source Intelligence (OSINT). The room demonstrates how to investigate suspicious infrastructure, identify malicious hosts, analyze exposed services, detect VPN usage, and leverage threat intelligence platforms to support security investigations.

---

# 🎯 Learning Objectives

- Understand IP and domain enrichment
- Investigate suspicious domains
- Analyze IP address reputation
- Identify exposed internet services
- Detect VPN and proxy infrastructure
- Perform threat intelligence investigations using OSINT
