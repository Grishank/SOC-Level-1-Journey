# 🧠 Room Overview

**Extracted** is a SOC investigation challenge focused on analyzing suspicious files and extracting valuable forensic evidence to uncover malicious activity. Rather than relying on a single data source, the investigation requires examining artifacts, identifying Indicators of Compromise (IOCs), and correlating findings to understand the attack.

The room emphasizes careful evidence collection, file analysis, and investigative thinking similar to real-world SOC operations.

# 💡 SOC Investigation Tips

- Always verify file hashes against trusted threat intelligence sources.
- Preserve original evidence before beginning analysis.
- Examine both file metadata and file contents for hidden clues.
- Correlate artifacts with endpoint and network evidence whenever possible.
- Document every finding to maintain a clear chain of evidence.
