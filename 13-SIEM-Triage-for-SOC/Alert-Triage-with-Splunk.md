# 🧠 Room Overview

This room introduces the practical workflow of **alert triage using Splunk**. As a SOC analyst, you investigate security alerts generated by detection rules, validate suspicious activity using Splunk searches, identify attacker techniques, and determine whether an alert is a true positive or a false positive.

The room walks through investigations involving **Initial Access**, **Persistence**, and **Web Shell** attacks while demonstrating how SIEM data supports incident response.

# 🔍 Typical Splunk Investigation Workflow

1. Receive security alert
2. Review alert details
3. Identify affected host
4. Examine related logs
5. Correlate events
6. Validate malicious activity
7. Determine attack stage
8. Assess impact
9. Document findings
10. Escalate if necessary

# 💡 SOC Analyst Investigation Tips

- Never rely on a single log source.
- Correlate endpoint, authentication, network, and web logs.
- Validate alerts before escalating.
- Look for attacker behavior rather than isolated events.
- Build a timeline to understand the attack progression.
