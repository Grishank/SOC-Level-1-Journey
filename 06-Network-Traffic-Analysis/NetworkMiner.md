# 🧠 Room Overview

**NetworkMiner** introduces one of the most powerful Network Forensics Analysis Tools (NFAT) used by incident responders and SOC analysts. The room demonstrates how NetworkMiner extracts valuable artifacts from packet capture (PCAP) files without requiring deep packet-by-packet analysis.

Instead of manually inspecting packets, analysts learn to recover files, images, credentials, DNS records, certificates, hosts, and sessions directly from captured network traffic.
