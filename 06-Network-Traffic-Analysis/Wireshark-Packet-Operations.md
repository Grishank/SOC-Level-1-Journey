# 🧠 Room Overview

Wireshark: Packet Operations expands on the fundamentals of Wireshark by introducing the tools and techniques used to efficiently inspect packet captures. The room covers traffic statistics, protocol analysis, and display filtering, enabling analysts to quickly identify relevant packets and investigate suspicious network activity.

These concepts are essential for SOC analysts, incident responders, and threat hunters who work with PCAP files during security investigations.

# 🎯 Learning Objectives

- Understand Wireshark's statistical analysis features
- Analyze protocol-specific network traffic
- Learn the principles of packet filtering
- Use protocol-based display filters
- Apply advanced filtering techniques
- Improve packet analysis and investigation efficiency

# 📌 Task 1 — Introduction

Introduced the concept of packet operations in Wireshark and explained how statistical analysis and filtering help analysts quickly locate important packets within large network captures.

# 📌 Task 2 — Statistics | Summary

Explored Wireshark's Statistics menu to obtain a high-level overview of captured traffic.

Covered:
- Total packet count
- Capture duration
- Average packet size
- Traffic rate
- Overall capture statistics

# 📌 Task 3 — Statistics | Protocol Details

Learned how Wireshark categorizes packets by protocol to provide insight into network communications.

Studied:
- Protocol Hierarchy
- Protocol distribution
- Traffic percentages
- Network protocol usage
- Communication breakdown

# 📌 Task 4 — Packet Filtering | Principles

Learned the fundamentals of display filtering to reduce unnecessary traffic and focus only on packets relevant to an investigation.

Covered:
- Display filters
- Filter syntax
- Efficient packet searching
- Targeted traffic analysis

# 📌 Task 5 — Packet Filtering | Protocol Filters

Practiced filtering captured packets using protocol-specific display filters.

Worked with filters for:
- HTTP
- DNS
- TCP
- UDP
- ICMP
- ARP

# 📌 Task 6 — Advanced Filtering

Explored advanced filtering techniques to isolate specific network events and suspicious communications.

Learned to filter using:
- IP addresses
- Port numbers
- Conversations
- Packet attributes
- Multiple filter conditions
- Logical operators (AND, OR, NOT)

# 📌 Task 7 — Conclusion

Reviewed the complete packet analysis workflow and reinforced how statistical analysis and filtering work together to speed up network investigations and improve detection accuracy.
