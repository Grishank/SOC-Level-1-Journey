# 🧠 Room Overview

**Windows Threat Detection 1** introduces common Windows **Initial Access** techniques used by attackers and explains how SOC analysts can detect them using Windows logs, endpoint telemetry, and user activity. The room focuses on identifying suspicious behavior related to Remote Desktop Protocol (RDP), phishing attacks, and infected USB devices.

---

# 🎯 Learning Objectives

- Understand Initial Access techniques
- Detect suspicious RDP activity
- Identify phishing-based compromises
- Recognize USB-based malware infections
- Analyze Windows security events
- Improve Windows threat detection skills
